Instant replay, library, editor and sharing for game clips on Linux (à la SteelSeries Moments),
built with GTK4 / libadwaita and using `gpu-screen-recorder` for capture. The UI is in French.

## Installation

```sh
./install.sh            # dependencies (Arch and derivatives) + Clips + replay service + shortcuts
./install.sh --force    # install even if some dependencies are missing
./uninstall.sh          # uninstall
```

Default shortcuts: <kbd>Alt</kbd>+<kbd>F10</kbd> save the replay ·
<kbd>Alt</kbd>+<kbd>F9</kbd> / <kbd>Alt</kbd>+<kbd>F11</kbd> start / stop a recording.
